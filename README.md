## 📝 Descripción
Este proyecto realiza un **Análisis Exploratorio de Datos (EDA)** enfocado en la **evasión de clientes (Churn)**, utilizando información contractual y financiera de los clientes.

El objetivo principal es **identificar patrones y factores clave** que influyen en la cancelación del servicio, proporcionando información valiosa para apoyar **estrategias de retención de clientes**.

---

## 🚀 Capacidades del proyecto
El proyecto permite:

- 📊 Analizar la **proporción de clientes que cancelan vs. los que permanecen**
- 👥 Evaluar el churn según **variables categóricas** como:
  - Género
  - Tipo de contrato
  - Método de pago
- 💰 Analizar variables numéricas clave:
  - Tiempo de contrato (*tenure*)
  - Gasto total
  - Gasto diario promedio (*Cuentas_Diarias*)
- 🧹 Realizar **limpieza y normalización de datos**
- 📈 Visualizar patrones mediante **gráficos claros y comparativos**
- 🔍 Generar **insights accionables** sobre el comportamiento del cliente
